# Interliner

**Taranmış eski kitapları okunur hale getiren ücretsiz bir Windows programı.**
PDF okuyucunuzda bir kelimeyi ya da satırı fareyle seçin; çevirisi ve isterseniz
açıklaması küçük bir balonda çıkar. Metin katmanı olmayan taranmış sayfaları da okur.

**[⬇ İndir (Windows)](https://github.com/zerars/interliner/releases/latest/download/Interliner.exe)**
· [Tüm sürümler](https://github.com/zerars/interliner/releases)

- Ücretsizdir; hesap açtırmaz, telemetri toplamaz.
- Ücretsiz çeviri anahtarsız çalışır. Yapay zekâ açıklamaları için kendi API anahtarınızı
  kullanırsınız (program adım adım nasıl alınacağını gösterir; Gemini'nin ücretsiz katmanı kart istemez).
- Program kendini günceller; her güncelleme imzayla doğrulanmadan kurulmaz.
- Gizlilik: [GIZLILIK.md](GIZLILIK.md) · KVKK: [KVKK.md](KVKK.md) · Lisans: [LICENSE.txt](LICENSE.txt)

Exe dosyası henüz bir sertifikayla imzalı değildir; Windows ilk açılışta "Windows bilgisayarınızı
korudu" diyebilir. **Ek bilgi → Yine de çalıştır** ile açılır.

## English

**A free Windows program that makes scanned old books readable.**
Select a word or a line in your PDF reader with the mouse; its translation, and an explanation
if you want one, appears in a small bubble. It also reads scanned pages that have no text layer.

**[⬇ Download (Windows)](https://github.com/zerars/interliner/releases/latest/download/Interliner.exe)**
· [All releases](https://github.com/zerars/interliner/releases)

- Free; no account, no telemetry.
- Free translation works without a key. AI explanations use your own API key (the program walks
  you through getting one; Gemini's free tier needs no card).
- Updates itself; every update is verified against a signature before it installs.
- The exe is not yet code-signed, so Windows SmartScreen may warn on first launch:
  **More info → Run anyway**.
